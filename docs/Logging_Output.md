# 桶体日志输出说明

本文档说明 `Application/log.c` 通过日志串口输出的信息，适用于串口调试工具查看桶体实时状态。

## 1. 输出通道与频率

- 默认日志端口为 `USART3`，波特率为 `115200`；当 `UART_PORT_DEBUG_SWAP_LOG_LINUX` 配置为非 0 时，日志端口切换为 `USART1`。端口选择和波特率见 `Communication/uart_port_config.h`。
- `Logging_TaskProcess()` 由日志任务每 `1000 ms` 调用一次，因此正常情况下每秒输出一行状态日志。
- 日志使用 UART DMA 和环形缓冲区异步发送，不应将其作为严格实时的时间基准；串口拥塞时日志可能延后或丢弃。
- 初始化成功后会先输出一行：`LOG is ready`。

## 2. 默认状态日志格式

默认编译配置为 `LOGGING_ENABLE_CURRENT_DEBUG = 1U`、`LOGGING_ENABLE_WATER_COUNT_DEBUG = 1U`，实际格式如下：

```text
[BUCKET] T:+38.5C BAT_NTC:+31.2C  W:12L  WC:25500Hz  BAT:24.3V DCIN:26.1V BASE:1 CHG:1 | ADC MOT:380mV PUMP:120mV | OUT M:2 P:1 H:1 UV:0 | ST:4/10 TS:600s CMD:A2 | I MOT:2533mA PUMP:40mA | ERR:00/00
```

各字段以 `|` 分为传感器、电源、ADC、输出、系统状态、电流和故障七组。

## 3. 字段含义

| 字段 | 含义 | 单位或取值 |
| --- | --- | --- |
| `T` | 桶内 NTC 温度 | `℃`；显示为 `-100.0C` 表示温度传感器无效。 |
| `BAT_NTC` | 电池 NTC 温度 | `℃`；显示为 `-100.0C` 表示电池温度传感器无效。 |
| `W` | 通信协议水位 | `L`，整数升，范围 0~20。 |
| `WC` | 水位传感器滤波后的脉冲频率 | `Hz`；仅在水位频率调试开关开启时打印。 |
| `BAT` | 电池实际电压 | `V`，由 `battery_decivolt` 的 0.1 V 值格式化得到。 |
| `DCIN` | 基站/DCIN 输入实际电压 | `V`，由 `dcin_decivolt` 的 0.1 V 值格式化得到。 |
| `BASE` | 基站在线状态 | `1`：DCIN 高于 13.0 V，且最近 3 秒收到合法基站帧；`0`：其余情况。 |
| `CHG` | 充电使能状态 | `1`：`DCIN_ON` 已允许充电；`0`：禁止充电。 |
| `ADC MOT` | 电机电流采样通道的 ADC 引脚电压 | `mV`，不是电机电流。 |
| `ADC PUMP` | 水泵电流采样通道的 ADC 引脚电压 | `mV`，不是水泵电流。 |
| `OUT M` | 按摩电机档位 | `0`：停止；`1`、`2`、`3`：对应按摩档位。 |
| `OUT P` | 水泵/阀门组合模式 | `0`：关闭；`1`：循环；`2`：排水。 |
| `OUT H` | 加热输出实际状态 | `1`：正在加热；`0`：未加热。 |
| `OUT UV` | UV 灯实际状态 | `1`：开启；`0`：关闭。 |
| `ST` | 系统主状态/子状态 | 格式为 `主状态/子状态`，主状态见下表；子状态由最近命令的参数写入，没有全局统一枚举。 |
| `TS` | 剩余定时时间 | `s`；未设置定时或定时到期时为 `0s`。 |
| `CMD` | 最近一次桶体命令 | 十六进制命令码，例如 `A2` 表示开启恒温。 |
| `I MOT` | 电机电流换算结果 | `mA`；仅在电流调试开关开启时打印。 |
| `I PUMP` | 水泵电流换算结果 | `mA`；仅在电流调试开关开启时打印。 |
| `ERR` | 错误码 1/错误码 2 | 两个十六进制位掩码，按位组合，见第 5 节。 |

`ADC MOT/PUMP` 用于排查传感器采样链路，`I MOT/PUMP` 才是按当前标定参数换算得到的电流。两者数值不应直接比较。

## 4. 主状态和常用命令

### 主状态 `ST` 的第一个数值

| 数值 | 名称 | 含义 |
| ---: | --- | --- |
| 0 | `POWER_ON` | 上电完成后的初始状态。 |
| 1 | `SELF_CHECK` | 自检中。 |
| 2 | `OFF` | 桶体关闭。 |
| 3 | `STANDBY` | 待机。 |
| 4 | `RUNNING` | 加热、按摩、UV 或自动补水等功能运行中。 |
| 5 | `LOW_POWER` | 电池低电保护状态。 |

### 常见 `CMD` 命令码

| 命令 | 含义 |
| --- | --- |
| `A0` | 关闭桶体。 |
| `A1` | 进入待机。 |
| `A2` / `A3` | 开启 / 关闭恒温。 |
| `A4` | 设置按摩档位。 |
| `A5` | 设置 UV 灯。 |
| `A6` | 设置定时。 |
| `A7` | 停止全部功能。 |
| `A8` | 启动自检。 |
| `A9` | 进入低功耗。 |
| `B2` | 自动补水。 |
| `B4` | 调试命令：水泵开启并切换至排水通路。 |
| `C0` | 请求系统复位。 |

`CMD:00` 表示空闲/心跳帧；系统初始化时默认命令为 `A1`。

## 5. 故障码 `ERR`

`ERR:xx/yy` 中的两个字节均为位掩码；多个故障会按位或组合。例如 `ERR:21/02` 表示错误码 1 同时包含缺水和水位传感器故障，错误码 2 包含水泵故障。

### 错误码 1（传感器、温度和水位）

| 位值 | 含义 |
| --- | --- |
| `01` | 缺水。 |
| `02` | 排水超时。 |
| `04` | 温度异常。 |
| `08` | 加热超时。 |
| `10` | 桶内温度传感器故障。 |
| `20` | 水位传感器故障。 |

### 错误码 2（执行器和电池）

| 位值 | 含义 |
| --- | --- |
| `01` | 加热模块故障。 |
| `02` | 水泵故障。 |
| `04` | 阀门故障。 |
| `08` | 电机故障。 |
| `10` | UV 灯故障。 |
| `20` | 电池电压异常。 |

## 6. 调试开关和限制

- 将 `LOGGING_ENABLE_CURRENT_DEBUG` 配置为 `0U` 后，状态行不会打印 `I MOT` 和 `I PUMP`。
- 将 `LOGGING_ENABLE_WATER_COUNT_DEBUG` 配置为 `0U` 后，状态行不会打印 `WC`。
- `Logging_Printf()` 的内部格式化缓冲区为 288 字节；单条消息超长时会被截断，`Logging_GetLastStatus()` 会返回 `HAL_BUSY`。
- 日志只反映读取瞬间的状态。排查保护动作时，应同时关注 `OUT`、`ST`、`ERR` 和对应任务的周期。

## 7. 代码对应关系

- 状态行生成：`Application/log.c` 的 `Logging_TaskProcess()`。
- 日志任务周期：`RTOS/rtos_tasks.c` 的 `RtosTasks_Logging()`。
- 传感器和电源字段：`Application/sensor.c`、`Application/power_manager.c`。
- 基站在线判断和命令码：`Communication/uart_comm.c`。
- 主状态、定时和错误码：`Application/system_monitor.c/.h`。
