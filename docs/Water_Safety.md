# 桶体用水功能保护

恒温、UV、内循环、按摩统一调用 Sensor_IsWaterSafe()。同一份已发布的传感器快照必须同时满足水位传感器有效、实际水量 >= SENSOR_WATER_MIN_SAFE_LITERS（目前 1.0 L）。

使用实际浮点升数，不使用四舍五入的协议水位。因此实际 0.6 L 即使上报 W:1L，也不允许启动。传感器未就绪或异常同样禁止启动。

| 功能 | 启动检查 | 运行中检查 |
|---|---|---|
| 恒温 | Temp_Enable；最终加热输出还检查一次，覆盖外部接管 | 温控任务约 100 ms；失水停热、取消使能和预循环，并关闭循环泵 |
| UV | UV_On（UV_Set 也经过此入口） | UV 任务约 50 ms；失水关闭 UV |
| 内循环 | PumpValve_SetMode；Pump_Start 和 Valve_Set 共用此入口 | 泵阀任务约 50 ms；失水关闭泵及阀 |
| 按摩 | Motor_SetLevel、Motor_Run，PWM 输出前复核 | 电机任务约 20 ms；失水清零档位及手动占空比并关闭 PWM |

恒温和 UV 运行中失水沿用原来的模块故障锁存，需按既有清错流程解除；启动前仅因缺水被拒绝不会新增模块故障。按摩、循环泵缺水停机不作为过流硬件故障锁存，补水后可接受新的启动请求。基站持续提出循环请求时，水位重新安全后允许循环，适用于自动上水过程。

上述时间是传感器已发布不安全水位后的任务检查周期，另有传感器采样、滤波和无脉冲超时的检测延迟。

排水不应用此最低水量门槛，否则无法完成排空。排水仍受原有基站/Linux 通信门禁、过流和排水超时保护。

实机应检查 0 L、0.6 L、1.0 L、运行中降至 1 L 以下及拔掉水位传感器，确认四项输出行为。
